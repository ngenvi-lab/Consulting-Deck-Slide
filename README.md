# Consulting Deck

Transform rough notes, raw data, and unstructured ideas into executive-ready deliverables formatted with the clarity, structure, and visual polish of top-tier management consulting decks and memos.

## Install (Claude Code)

```
/plugin marketplace add ngenvi-lab/Consulting-Deck-Slide
/plugin install consulting-deck@ngenvi-lab
```

## Layout

```
.claude-plugin/
  plugin.json            plugin manifest
  marketplace.json       lets this repo be added as a marketplace
skills/consulting-deck/
  SKILL.md               the skill (style + logic rules)
  assets/deck.css        shared stylesheet
  references/examples/   template slides (fictional data)
```
